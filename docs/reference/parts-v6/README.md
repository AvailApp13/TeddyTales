# Детали v6 — мишка, разобранный на части

Нарезано `tool/cut_parts.py` из выровненных кадров `docs/reference/plush-v6`.
Девять деталей, 5,8 МБ в WEBP q92.

| Деталь | Из кадра | Размер | Позиция на холсте |
|---|---|---|---|
| `torso` | 0calm | 1620 × 980 | 430, 1540 |
| `legs` | 0calm | 1200 × 930 | 660, 2330 |
| `head_calm` | 0calm | 1370 × 1680 | 560, 80 |
| `head_happy` | 1happy | 1370 × 1680 | 560, 80 |
| `head_sad` | 2sad | 1370 × 1680 | 560, 80 |
| `head_sleep` | 3sleep | 1370 × 1680 | 560, 80 |
| `head_chew` | 4chew | 1370 × 1680 | 560, 80 |
| `head_gazeL` | 8gazeL | 1370 × 1680 | 560, 80 |
| `head_gazeR` | 9gazeR | 1370 × 1680 | 560, 80 |

Все семь голов вырезаны одной рамкой из кадров, сведённых на одну сетку, —
поэтому у них общая позиция и подмена одной на другую не сдвигает мишку ни
на пиксель.

Самих файлов в репозитории нет: 5,8 МБ бинарников, которые собираются за
полторы минуты из облачных исходников. Воспроизводится так:

```
python3 tool/align_plush.py aligned/ raw/*.png
python3 tool/cut_parts.py  parts/   aligned/*.png
```

`raw/` качается по job id из `docs/reference/plush-v6/README.md`.

## Где проходит шов

Голова кончается на y = 1760, корпус начинается на y = 1540 — перекрытие
220 пикселей. Голову рисуем поверх корпуса, поэтому под ней всегда есть
тело: голова может смещаться примерно на ±110 пикселей, и дыры не будет.

Шов выбран не на глаз. По силуэту кадра `0calm` шея — самое узкое место
всего мишки: на y ≈ 1600 ширина падает до 863 пикселей, тогда как на
уровне плеч она 1572. Шов идёт по этому перехвату, где он и прячется.

## Проверка

`assembly-check.webp`. Сверху — семь мишек, каждый собран заново из
`legs` + `torso` + своя голова. Снизу — шея крупным планом в трёх фазах
дыхания: голова поднята на 35 пикселей и корпус выше на 3 %, покой,
голова опущена на 12 и корпус ниже на 1 %. Стыка не видно ни в одной фазе.

## Чего этими деталями пока нельзя

Лапы сидят внутри `torso` и отдельно не двигаются, значит нет ни взмаха,
ни хлопка, ни ходьбы. Для них нужна отдельная нарезка рук с шарниром в
плече и кадр с поднятой лапой (`6wave` уже снят).
