# Плюшевые варианты v5 — источник деталей для рига

Шесть вариантов одного и того же мишки, полученные по цепочке из
`docs/reference/3d/REPORT.md`: 3D-модель задаёт позу и камеру, фото
настоящей игрушки задаёт внешний вид, `gpt_image_2_5` сводит одно с другим.

`moods-6.webp` — контакт-лист (уменьшенный, для просмотра).
`heads-4.webp` — крупные головы первых четырёх.

## Что сгенерировано

| # | Что | Job |
|---|---|---|
| 0 | спокойный: глаза открыты, рот закрыт мягкой улыбкой | `22bc1b11-ea46-4766-a32b-8e6d805703cc` |

Оригиналы — PNG 1744 × 2336 с альфой, ~5,5 МБ каждый, лежат в облаке
Higgsfield. В репозиторий не кладутся: CDN Higgsfield закрыт egress-прокси
нашей среды, файлы вынимаются только через песочницу, и 33 МБ через этот
канал таскать незачем — по job id они перевыкачиваются за секунды.

Параметры генерации: `gpt_image_2_5`, variant flare, quality high,
resolution 2k, aspect 3:4, background transparent, два референса —
рендер 3D (`1688c2a6-…`) и фото игрушки (`06816d89-…`).

## Что получилось хорошо

Ворс с отдельными ворсинками, пушистый контур, блик в чёрных глазах-бусинах,
вышитый нос, фактура хлопка на капюшоне и шортах, шов по краю капюшона,
ярлычок на бедре. Это тот же мишка во всех шести — не «похожий».

## Что нужно доделать перед нарезкой

1. **Выравнивание.** Генерации независимые, поэтому масштаб и положение
   гуляют: у грустного (#2) голова мельче, капюшон уже. Перед нарезкой все
   кадры надо привести к одной сетке по центру носа и ширине капюшона.
2. **Вариант #4 не выполнил задачу** — просил поднять одну лапу, вышли обе
   слегка разведённые. Перегенерировать с более жёсткой формулировкой.
3. **Рот.** Нужен ещё как минимум «маленькое о» (удивление) и «жуёт»
   для кормления — в этой партии их нет.
