## Общая сетка

Все десять сведены `tool/align_plush.py` на холст 2480 × 3307: высота тела
3150, низ на y = 3250, центр по x = 1240. Коэффициенты масштаба вышли
1,010–1,071 — то есть кадры почти не пересэмплируются, родное разрешение
сохраняется.

`bodies-10.webp` — весь набор целиком, `heads-10.webp` — головы крупно.

## Где что лежит на холсте

Замерено по цвету на кадре 0 (`0calm`), координаты в пикселях холста:

| Область | Габарит |
|---|---|
| синее (капюшон и кофта) | x 476–1984, y 102–2439 |
| мех (весь) | x 462–2007, y 655–3246 |
| глаза и нос (тёмное в верхней части) | x 749–1746, y 1080–1488 |
| левый глаз | x 749–1240, y 1080–1470 |
| правый глаз | x 1240–1746, y 1080–1488 |

Голова с капюшоном, ушами и мордой целиком укладывается в
`(420, 80, 2060, 1880)` — по этой рамке и сняты крупные планы.

## Что получилось

Ворс распадается на отдельные ворсинки, у чёрных глаз-бусин честный блик,
нос вышит, на капюшоне читается строчка по краю и фактура хлопка, белая
пуговица на месте, ярлычок на бедре тоже. Форма капюшона и пропорции морды
держатся одинаковыми во всех десяти — это один мишка, а не десять похожих.

## Что не получилось

1. **Удивление (#7) не сыграло.** Просил рот маленьким «о» — вернулась
   почти та же мягкая улыбка. Нужна перегенерация с другой формулировкой.
2. **Обе лапы вверх (#5)** подняты меньше, чем просили: лапы разведены в
   стороны, а не вскинуты над плечами. Для «ура» сойдёт, для замаха нет.
3. **Грусть (#2) читается слабо** на общем плане — различима только вблизи.
   Если по механике нужно узнавать настроение с расстояния, придётся
   усиливать наклон головы.
