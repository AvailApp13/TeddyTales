# Бриф художнику

## Что нужно

Мишка **раздельными слоями**, не готовой анимацией. Анимацию собираем мы в
Rive: риг, кости, state machine.

Два героя (КП: 2 героя) — мальчик и девочка, отдельными файлами с одинаковым
набором имён слоёв.

## Правило именования

Каждая часть — отдельный слой, имя строго `snake_case`, латиницей, по списку
ниже. Точное совпадение важнее красоты: по этим именам код приложения находит
части, и опечатка ломает анимацию.

Полный список — `handoff/expected_layers.txt` (44 слоя). Сгенерировать заново:

    node tools/bin/teddy.mjs layers

Дерево с родителями — `node tools/bin/teddy.mjs tree`.

## Группы

| Группа | Слои |
|---|---|
| Тело | `body`, `body_base`, `head`, `head_shadow` |
| Руки (для каждой стороны `_left` / `_right`) | `forearm`, `forearm_light`, `hand`, `hand_light`, `finger_1_nail`, `finger_2_nail`, `finger_3_nail` |
| Уши (для каждой стороны) | `ear`, `ear_in`, `ear_light` |
| Глаза (для каждой стороны) | `eye`, `pupil`, `pupil_light`, `eyelid_top`, `eyelid_bottom`, `eyebrow` |
| Лицо | `nose`, `mouth`, `teeth`, `tongue`, `lips` |
| Шарф (опционально) | `scarf_1`, `scarf_2`, `scarf_3` |

Блики (`*_light`) и внутренние части (`ear_in`) — **отдельными слоями**: они
двигаются самостоятельно, слитые с основой они мертвеют.

Рот нужен со **всем содержимым** — зубы, язык, губы отдельно: по КП 4.3 есть
кормление и умывание, там рот открывается.

## Одежда (КП 4.9, 10.5)

Четыре слота, каждый — отдельным файлом или отдельной группой:

| Слот | Имя | Сколько | Крепится к |
|---|---|---|---|
| Комплект | `outfit_body` | 8 | корпус |
| Головной убор | `outfit_head` | 3 | голова |
| Обувь | `outfit_feet` | 2 | корпус |
| Аксессуар | `outfit_accessory` | 3 | корпус |

Одежда должна двигаться вместе с телом и не съезжать — рисовать с запасом на
деформацию в местах сгиба.

## Технические требования

- Вектор (SVG или исходник Illustrator / Figma).
- Слои не растрировать, не объединять, маски не «запекать».
- Ничего не поворачивать «намертво»: повороты делает риг.
- Одинаковый размер холста во всех файлах.
- Персонаж в нейтральной позе, анфас, симметрично — из неё строится риг.

## Проверка перед отправкой

Выгрузите список слоёв и прогоните:

    node tools/bin/teddy.mjs check handoff/incoming/bear.svg

Отчёт отдельно показывает опечатки (переименовать — минута) и отсутствующие
слои. Зелёный отчёт — можно передавать.
