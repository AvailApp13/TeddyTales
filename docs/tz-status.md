# Сверка с ТЗ и что ждёт согласования (26.09)

Логический прогон всех функций 26.09 по просьбе заказчика: порядок окон,
пробелы по ТЗ (`docs/tz-app.md`) и по логике использования. Что решено —

## Порядок окон при входе

1. Загрузка (без сети — с сохранённого, КП 1.1).
2. Стартовая страница: почта или «Пропустить» (КП 1.2).
3. Первый запуск: «Родился малыш!» → «Как зовут малыша?» → код друга.
4. Главный экран: монеты пригласившему → «Сегодня» (подарок дня) → код
   из ссылки (веб) → «Напоминать о малыше?» (со второго дня) → «Гостил у
   бабушки».

Каждое следующее окно ждёт, пока закроется предыдущее.

## Сверх ТЗ — предложения Ирине (бонус), не делаем до «да»

- **«Сохрани мишку».** Гость (нажал «Пропустить») на 2–3-й день видит:
  «Сохрани {имя}, чтобы не потерять при смене телефона» → почта или
  Apple. Сейчас гость, переустановив приложение, теряет мишку.
- **Подсказки первых шагов.** После имени три коротких подсказки
  поверх комнаты: кольца показателей («нажми — узнаешь, чего хочет»),
  лапа-меню («комнаты, магазин, игры»), «Сегодня» («подарок каждый день»).
  Показываются один раз.
