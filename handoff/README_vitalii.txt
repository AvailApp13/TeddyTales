МИШКА-МАЛЬЧИК v2 — всё для работы
Ветка: AvailApp13/TeddyTales, claude/hero-animation-setup-exnpp8
Та же структура лежит в ветке (handoff/, rig/, tools/scripts/) — это основная копия.

1_approved_bear/bear_boy_v2_full.png
    Утверждённый мишка: Higgsfield, без бирки, прозрачный фон, 1333×2000.
    Всё остальное делается из него.

2_rig_layers/  — 9 слоёв для Rive
    ears, face, foot_left, foot_right, shorts, paw_left, paw_right, shirt, hood
    (порядок сзади вперёд — в layers.json).
    Каждый слой — полный кадр 1333×2000 с прозрачностью. Ставятся ОДНИМ общим
    трансформом и складываются обратно в утверждённого мишку без отличий.
    В артборде Bear_Boy (1024×1024): центр картинки 505.7, 480.5,
    масштаб 62.98 %.
    Капюшон отрезан по контуру подбородка с ободом; край меха у ткани отдан
    переднему слою; под соседом каждый слой заходит на 3 px своим цветом —
    при движении стык не светится. Светлый ореол по краю снят.

3_hidden_parts/  — запас из Higgsfield
    head, ears, body, arm_left, arm_right, leg_left, leg_right,
    outfit_head, outfit_body, outfit_feet, face_features.
    Нужны под зоны, которых на кадре не видно (макушка под капюшоном, плечи,
    бёдра, шея) — подставляются скрытыми под слои, когда части двигаются.
    В редактор пока не поставлены.

4_rive/
    bear_boy_v2.rev   — файл редактора Rive (открыть: Rive → Import / перетащить
                        в проект). Резервная копия со всеми слоями и группами рига.
    bear_boy_v2.riv   — тот же файл для рантайма (приложение, лаборатория).
    bear_skeleton_cli.riv / .rml — каркас рига из Rive CLI (кости, View Model,
                        State Machine, заготовки 112 клипов) без арта.

5_grid_and_spec/
    bear_proportions.json — размерная сетка, снятая с этого мишки
                            (единица — рост без капюшона).
    bear_rig.json         — имена костей, узлов, свойств View Model, состояний.
    animation_catalog.json — каталог клипов по КП, раздел 4.
    editor_state.json     — id объектов в файле Rive (файл 2604781).

6_scripts/
    split_full_bear.py  — режет утверждённого мишку на 9 слоёв.
    measure_bear_v2.py  — снимает сетку с мишки.
    place_layers_v2.mjs — ставит слои в открытый Rive через MCP (нужен туннель).
    mac_upload_parts.py — грузит PNG в открытый Rive прямо с мака.

7_checks/
    Сравнения: утверждённый мишка против сборки из слоёв и против снимка
    редактора; лист со всеми слоями.

Следующий шаг: кости (координаты — node tools/bin/teddy.mjs mcp:bones),
затем пробное движение головы и лап, подстановка скрытых частей под стыки.
