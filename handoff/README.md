# Передача от художника

Сюда кладём то, что присылает художник, и здесь же проверяем именование до того,
как открывать Rive Editor.

    handoff/incoming/   — присланные файлы, в git не попадают (.gitignore)
    handoff/*.txt       — выгруженные списки слоёв, их коммитим как историю проверок

## Проверка

    cd tools
    node bin/teddy.mjs layers                 # что вообще должно быть прислано
    node bin/teddy.mjs check ../handoff/incoming/bear.svg

Команда понимает `.svg` (id / data-name / inkscape:label), `.json`
(`["имя", ...]` или `{"layers": [...]}`) и `.txt` — по одному имени в строке.

Отчёт разделяет «похоже на опечатку» (переименовать — одна минута) и
«слоя нет вовсе» (перерисовывать). Опциональные слои — шарф — на MVP не
блокируют: см. открытый вопрос Q5.
