# assets/rive

Сюда кладутся экспортированные из Rive Editor файлы.

Требования к ригу — `docs/tz-animator-v2.md` (редакция 2, растровый
конвейер). Старый `docs/tz-animator.md` действует только в части, которую
редакция 2 не отменяет; таблица отличий — в её разделе 0.

| Файл | Что это | Константа в коде |
| --- | --- | --- |
| `bear_slow.riv` / `bear_joy.riv` | основной персонаж по героям: артборд и State Machine `bear_main`, 85 клипов + 6 служебных таймлайнов | `BearRigSpec.assetPath` |
| `birth_scene.riv` | сцена рождения, отдельный артборд, вне основной State Machine | `BearRigSpec.birthSceneAssetPath` |
| `demo_monster.riv` | временная заглушка, сторонний файл — см. ниже | `BearRigSpec.demoAssetPath` |

Пока `bear_main.riv` нет, `BearView` рендерит плейсхолдер вместо падения —
приложение собирается и запускается без рига.

## Требования к экспорту

- Тариф Rive **Cadet** ($9/мес) — безлимитный экспорт `.riv` для продакшена.
- Naming convention в файле: `Workspace → Admin → Options → Naming convention → snake_case`.
- Размер: не более 3 МБ для `bear_main.riv`, не более 4 МБ для `birth_scene.riv`
  (раздел 9 ТЗ аниматора).
- Имена артборда, State Machine и всех входов должны совпадать с
  `lib/bear/bear_rig_spec.dart`. Если в редакторе имена другие — правится один
  файл спецификации, код трогать не нужно.
- **Артборд сдаётся с прозрачным фоном.** У самого артборда не должно быть
  заливки — в редакторе это «цвет фона артборда», и рантайм её честно рисует.
  Фигур во весь артборд с видимой заливкой тоже быть не должно. Фон рисует
  приложение: персонаж стоит поверх сцены комнаты, и любая подложка в `.riv`
  просто закроет её. Отключить подложку из кода нельзя: рантайм умеет только
  вписать артборд в область. Проверяется автоматически — `tool/riv_lint.py`.
  Фигура во весь артборд с выключенной заливкой — это, наоборот, штатный
  приём: невидимая хит-зона под слушателя.

## Временная заглушка `demo_monster.riv`

Сторонний файл, взят только чтобы проверить пайплайн до прихода рига.
У него был собственный фон — заливка, повешенная прямо на артборд (`Fill`
с родителем `comp[0]`), с почти чёрным градиентом, из-за которого в приложении
вместо кремовой комнаты получался чёрный экран. Обе точки градиента погашены
до прозрачного:

    python3 tool/riv_paint.py set assets/rive/demo_monster.riv 809=00000000 810=00000000

Правка сделана по месту (цвет в `.riv` — это uint32 ARGB, длина файла и индексы
объектов не меняются). Удалить объект нельзя: ссылки на родителей в формате
идут по индексам. Удалить весь файл — можно и нужно, как только придёт
`bear_main.riv`.
