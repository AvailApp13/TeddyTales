# assets/rive

Сюда кладётся экспортированный из Rive Editor файл рига медведя.

Ожидаемое имя файла: **`bear.riv`** (константа `BearRigSpec.assetPath` в
`lib/bear/bear_rig_spec.dart`).

Пока файла нет, `BearView` рендерит плейсхолдер вместо падения — приложение
собирается и запускается без рига.

## Требования к экспорту

- Тариф Rive **Cadet** ($9/мес) — безлимитный экспорт `.riv` для продакшена.
- Naming convention в файле: `Workspace → Admin → Options → Naming convention → snake_case`.
- Имена артборда, State Machine и свойств View Model должны совпадать с
  константами в `bear_rig_spec.dart`. Если в редакторе имена другие —
  правится один файл спецификации, код трогать не нужно.

## Чеклист именования слоёв (для художника)

Полная конвенция — в `docs/rig-naming.md` (раздел 3 ТЗ).
